# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Use GitHub's private reporting instead: go to the
[Security tab](https://github.com/mohamedtaqysalmi/darija-eval-set/security) and choose "Report a vulnerability".

I maintain this project alone, so expect a first reply within a few days rather than hours.

## Supported versions

The project is at an early stage. Only the latest release on `main` is supported.
